Record once. Search before the next CUA loop.

VAMP exists to stop re-deriving the same GUI work. The hub is where those recordings are found, compared and reused.

01

Record in a guest

A human or CUA performs the task inside a VAMP VM. The guest recorder writes PyAutoGUI source; the host parses it without ever executing it.

02

Save an input contract

Declare ${placeholders}, the expected result and the review state. The skill is versioned per folder, with its own Git history.

03

Reuse, then verify

An agent runs rpa_search first, replays a match with rpa_run_saved, and checks the expected result before reporting success.
